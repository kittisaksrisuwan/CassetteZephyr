# CassetteZephyr

CassetteZephyr employs a cassette-based, Zephyr-enabled architecture for real-time data leveraging auto-scaling for Zephyr workloads on the Zephyr platform.

With CassetteZephyr, you get a lightweight tool that stays out of your way.

**What you get**

- CassetteZephyr employs a cassette-based, Zephyr-enabled
- architecture for real-time data leveraging
- auto-scaling for Zephyr workloads on

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CassetteZephyr.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CassetteZephyr is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
